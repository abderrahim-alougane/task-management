# 📝 Task Manager (Flask)

A simple task management web app built with Python and Flask.  
It lets users add, mark as done, and delete tasks — all stored in memory (no database).

## 🚀 Features

- Add new tasks
- Mark tasks as done
- Delete tasks
- Tasks stored temporarily (in memory)
- Uses Bootstrap for styling
